1. Pendência Selecionada e Priorização Prioridade: ALTA

Funcionalidade Escolhida: Integração B2B via WhatsApp API (UC05) — Geração automática de link parametrizado para atendimento e pós-venda direto no WhatsApp comercial, enviando o ID do pedido, lista de softwares contratados e razão social da empresa cliente.

Justificativa Técnica: Na comercialização de sistemas de gestão e licenças corporativas (B2B), o pós-venda imediato (liberação de chaves, parametrização fiscal e treinamento de implantação) é determinante para a retenção do cliente. Anteriormente, o comprador precisava informar manualmente seus dados ao suporte. Com a construção do motor src/lib/whatsapp.ts integrado aos modelos Order, Product e User do Prisma ORM, o sistema compila dinamicamente o ID do pedido, a Razão Social (companyName), o CNPJ/Inscrição Estadual e a lista numerada de softwares contratados, codificando o payload via encodeURIComponent diretamente para a API oficial do WhatsApp.

2. Resultado Esperado e Comportamento Alcançado 100% Homologado

Assim que o cliente conclui uma compra em /checkout/[id] ou acessa /minha-conta, a aplicação disponibiliza botões inteligentes de Atendimento e Pós-Venda via WhatsApp Comercial (UC05). Ao clicar, o navegador redireciona para https://api.whatsapp.com/send?phone=...&text=... com o resumo corporativo completo já preenchido. Adicionalmente, no Painel Administrativo (/admin/pedidos), cada pedido conta com o botão Pós-Venda B2B que permite ao gestor da HJ Infor acionar ativamente a empresa compradora no WhatsApp informando o status atualizado da licença.

6.1 Construtor Parametrizado em src/lib/whatsapp.ts
export function buildCommercialWhatsAppUrl( payload: WhatsAppB2BPayload, commercialPhone: string = HJ_INFOR_COMMERCIAL_WHATSAPP ): string { const cleanPhone = commercialPhone.replace(/\D/g, ""); const softwaresList = payload.softwares .map((item, idx) => `${idx + 1}. [Pedido #${item.orderId?.slice(0, 8).toUpperCase()}] ` + `*${item.softwareName}* (${item.quantity} licença(s))` ) .join("\n"); const lines = [ `*[CORELINK B2B — ATENDIMENTO E PÓS-VENDA]*`, `🏢 *Razão Social / Empresa:* ${payload.companyName}`, `🔖 *ID do Pedido:* #${payload.orderId.slice(0, 8).toUpperCase()}`, `💻 *Lista de Softwares Contratados:*`, softwaresList, ]; return `https://api.whatsapp.com/send?phone=${cleanPhone}&text=${encodeURIComponent(lines.join("\n"))}`; }
