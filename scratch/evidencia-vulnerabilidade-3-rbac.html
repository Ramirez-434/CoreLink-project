HJ Infor — Verificação Estrita de Papéis no Middleware (src/proxy.ts) e Revalidação PostgreSQL em /admin/pedidos/export

1. Vulnerabilidade Selecionada e Priorização

Vulnerabilidade Mitigada

Vulnerabilidade 3 (Risco de Bypassing Administrativo): Falta de verificação estrita de papéis no middleware permitia tentativas de requisição não autorizada à rota de exportação CSV (/admin/pedidos/export).

Justificativa Técnica: Na arquitetura do Next.js App Router, o arquivo src/app/admin/layout.tsx protege apenas componentes de página (page.tsx), não sendo executado para Route Handlers como /admin/pedidos/export/route.ts. Sem um Middleware/Proxy global (src/proxy.ts) na borda da aplicação e sem revalidação do papel (role === "ADMIN") diretamente no PostgreSQL, tentativas de acesso direto por usuários autenticados com perfil CUSTOMER ou portadores de tokens JWT antigos/revogados não eram barradas no perímetro de rede.

2. Resultado Esperado e Comportamento Alcançado

RBAC Dupla Camada Ativo

Foi implementada uma defesa de Controle de Acesso Baseado em Papéis (RBAC) em 2 camadas: (1) Middleware Global na Borda (src/proxy.ts + src/lib/rbac-middleware.ts) interceptando /admin/:path* antes do roteamento, retornando 401 Unauthorized para requisições anônimas e 403 Forbidden (RBAC_FORBIDDEN_403) para clientes comuns tentando acessar /admin/pedidos/export; e (2) Revalidação no Banco PostgreSQL (route.ts) confirmando se o usuário mantém role === "ADMIN" ativa no banco antes de gerar o CSV, além de sanitização contra CSV Formula Injection.

Código & Telemetria
6.1 Middleware RBAC (src/lib/rbac-middleware.ts & src/proxy.ts)
export function evaluateAdminRbacMiddleware(
  req: NextRequest, user: AuthenticatedSessionUser | null | undefined
): NextResponse | null {
  const { pathname } = req.nextUrl;
  const isExportOrApi = pathname.startsWith("/admin/pedidos/export");

  if (pathname.startsWith("/admin")) {
    if (!user || !user.id) {
      if (isExportOrApi)
        return NextResponse.json(
          { success: false, code: "AUTH_REQUIRED_401" }, { status: 401 }
        );
      return NextResponse.redirect(new URL("/login", req.nextUrl.origin));
    }
    if (user.role !== "ADMIN") {
      if (isExportOrApi)
        return NextResponse.json(
          { success: false, code: "RBAC_FORBIDDEN_403", requiredRole: "ADMIN" },
          { status: 403 }
        );
      return NextResponse.redirect(new URL("/minha-conta?erro=acesso-restrito-admin", req.nextUrl.origin));
    }
  }
  return null;
}
