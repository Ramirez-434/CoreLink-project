1. Vulnerabilidade Selecionada e Priorização

Vulnerabilidade Mitigada

Vulnerabilidade 1 (Sanitização e Input Injection): O backend aceitava strings sem filtragem prévia para CNPJ/CPF e campos correlatos no perfil corporativo, permitindo injeção de parâmetros maliciosos ou formatação inconsistente.

Justificativa Técnica: A ausência de sanitização prévia e de verificação algorítmica nos endpoints updateUserProfile (src/actions/user.ts) e registerUser (src/actions/auth.ts) permitia: (1) envio de vetores XSS/HTML (<script>), SQLi e injeção de parâmetros na integração WhatsApp API (UC05); (2) aprovação de CNPJs/CPFs forjados com sequências repetidas (00.000.000/0000-00) ou dígitos verificadores inválidos; e (3) gravação inconsistente no PostgreSQL (ora apenas números, ora com pontuação parcial).

2. Resultado Esperado e Comportamento Alcançado

Validação Módulo 11 Ativa

Foi construído o módulo src/lib/sanitize.ts aplicado no cliente (ProfileForm.tsx), nas Server Actions (user.ts e auth.ts) e no gerador WhatsApp (whatsapp.ts). Qualquer tentativa de injeção (hasMaliciousInjection) é imediatamente bloqueada e registrada em log. O campo CNPJ/CPF passa por extração numérica estrita (onlyDigits), cálculo dos 2 Dígitos Verificadores Módulo 11 (isValidCPF / isValidCNPJ) e normalização canônica obrigatória (XX.XXX.XXX/XXXX-XX ou XXX.XXX.XXX-XX) antes de gravar no Prisma ORM.

6.1 Validação Algorítmica CNPJ e Anti-Injection (src/lib/sanitize.ts)
export function isValidCNPJ(raw: string | null | undefined): boolean {
  const digits = onlyDigits(raw);
  if (digits.length !== 14 || /^(\d)\1{13}$/.test(digits)) return false;

  const calcDigit = (slice: string, weights: number[]): number => {
    const sum = weights.reduce((acc, w, i) => acc + Number(slice[i]) * w, 0);
    const mod = sum % 11;
    return mod < 2 ? 0 : 11 - mod;
  };
  const w1 = [5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2];
  const w2 = [6, 5, 4, 3, 2, 9, 8, 7, 6, 5, 4, 3, 2];

  return (
    calcDigit(digits.slice(0, 12), w1) === Number(digits[12]) &&
    calcDigit(digits.slice(0, 13), w2) === Number(digits[13])
  );
}

export function validateAndSanitizeDocument(raw: string | null | undefined) {
  if (hasMaliciousInjection(raw) || /[a-zA-Z<>;'"`\\]/.test(raw || "")) {
    return { valid: false, type: "INVALID", formatted: null,
      error: "Entrada bloqueada: tentativa de injeção detectada." };
  }
  const digits = onlyDigits(raw);
  if (digits.length === 14 && isValidCNPJ(digits))
    return { valid: true, type: "CNPJ", formatted: formatCpfCnpjMask(digits) };

}
