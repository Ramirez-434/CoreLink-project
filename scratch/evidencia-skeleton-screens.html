1. Pendência Selecionada e Priorização

CLS = 0.00 (Zero Shift)

Funcionalidade Escolhida: Telas Esqueléticas (Skeleton Screens) — Adição de loaders visuais no catálogo e nos cards do dashboard enquanto as rotas assíncronas do backend respondem.

Justificativa Técnica: Nas rotas que realizam agregações analíticas e consultas ao banco PostgreSQL serverless (Neon Cloud), a renderização tradicional bloqueava a exibição da página até o término de todas as queries ou provocava saltos bruscos de layout (Cumulative Layout Shift — CLS). A adoção de Skeleton Screens combinada ao React Server Components Streaming (<Suspense>) e boundaries loading.tsx entrega o shell visual imediatamente (TTFB < 30ms) e mantém a geometria exata dos cards enquanto o backend responde.

2. Resultado Esperado e Comportamento Alcançado

Streaming Ativo

Foi desenvolvida a biblioteca central src/components/ui/Skeleton.tsx com suporte a Dark Mode e acessibilidade (role="status", aria-busy="true"). No catálogo (/sistemas), o cabeçalho é renderizado instantaneamente enquanto <CatalogGridSkeleton count={6} /> pulsa no lugar dos 6 cards de software. No Painel Administrativo (/admin/dashboard e /admin/pedidos), os 4 cards de KPIs, os 2 gráficos Recharts (Evolução & Donut) e as tabelas exibem esqueletos sincronizados tanto no carregamento inicial quanto na troca de período (PeriodFilter.tsx).

6.1 Primitivo e Cards em src/components/ui/Skeleton.tsx
export function Skeleton({ className = "" }: SkeletonProps) {
  return (
    <div
      role="status"
      aria-busy="true"
      aria-label="Carregando conteúdo..."
      className={`animate-pulse rounded-xl bg-gray-200/90 dark:bg-gray-700/70 ${className}`}
    />
  );
}

export function DashboardKpiCardsSkeleton() {
  return (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6 mb-8">
      {Array.from({ length: 4 }).map((_, idx) => (
        <div key={idx} className="bg-white dark:bg-gray-800 p-6 rounded-2xl flex items-center gap-4">
          <Skeleton className="w-14 h-14 rounded-full shrink-0" />
          <div className="flex-1 space-y-2.5">
            <Skeleton className="h-3.5 w-28 rounded-md" />
            <Skeleton className="h-7 w-36 rounded-lg" />
          </div>
        </div>
      ))}
    </div>
  );
}
